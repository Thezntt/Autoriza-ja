# Registros de Decisão Arquitetural (ADR)

Detalhes e justificativas no [Documento de Arquitetura](../fase-2/01-Documento_de_Arquitetura_de_Software.pdf), seção 9.

| ADR | Decisão |
|---|---|
| ADR-01 | Monólito modular |
| ADR-02 | TypeScript no front e no back |
| ADR-03 | NestJS em vez de Express puro |
| ADR-04 | PostgreSQL como banco relacional |
| ADR-05 | Fila (BullMQ/Redis) para notificações e integração |
| ADR-06 | PWA em vez de app nativo |
| ADR-07 | Prazos regulatórios parametrizáveis em tabela |
| ADR-08 | IA apenas para resumo de documentos, nunca para decisão |
